# Bath crate (щайгичка за баня) — ASA

200 × 100 × 50 mm (+3 mm feet), slatted walls, drainage floor, handle cut-outs on the short sides.

- `bath_crate.scad` — parametric source (L/W/H, wall, slot sizes, hole size).
- `bath_crate.stl` — export.

## Print (Bambu H2S, 0.6 nozzle, ASA)
- Orientation: as exported (floor down). No supports.
- Layer 0.3 mm, 3 walls, 4 top/bottom layers, 15% infill.
- ASA: 260–270 °C nozzle, bed 100 °C, door closed, chamber warm, brim 5 mm.
